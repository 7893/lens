# ADR-0000: 架构决策记录模板

责任人：@author
适用范围：描述该决策适用的模块或系统范围

---

## 背景 (Context)

描述导致该项决策的技术背景、业务驱动力或既有架构痛点。

- 当前遇到了什么问题？
- 有哪些硬性约束（成本、性能限制、合规、生态）？

## 决策 (Decision)

清晰明确地陈述做出了什么技术决定。

- 采用什么方案/架构/工具？
- 具体的实现方式与契约约束是什么？

## 理由与考量 (Rationale)

解释做出该决定的技术原因以及评估过的替代方案：

1. **优势对比**：为什么选择此方案而非候选方案 A / B？
2. **权衡考量**：接受了什么妥协（Trade-offs）？

## 影响与后果 (Consequences)

记录该决策落地后的正面与负面影响：

- **正面收益**：性能提升、成本降低、开发效率改善等。
- **潜在风险与负面影响**：引入的新依赖、迁移成本、维护负担等。
- **后续待办**：是否有后续配套动作需要跟进？
